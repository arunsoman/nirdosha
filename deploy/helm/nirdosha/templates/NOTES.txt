nirdosha is deploying as a {{ if eq .Values.db.mode "postgres" }}Deployment ({{ .Values.replicaCount }} replica(s), Postgres-backed durability){{ else }}StatefulSet (1 replica, local SQLite + PersistentVolumeClaim){{ end }}.

Check rollout status:
  {{- if eq .Values.db.mode "postgres" }}
  kubectl rollout status deployment/{{ include "nirdosha.fullname" . }} -n {{ .Release.Namespace }}
  {{- else }}
  kubectl rollout status statefulset/{{ include "nirdosha.fullname" . }} -n {{ .Release.Namespace }}
  {{- end }}

Probe the health/readiness routes (see docs/KUBERNETES.md's "Health &
lifecycle" row) from inside the cluster:
  kubectl exec -n {{ .Release.Namespace }} {{ include "nirdosha.fullname" . }}-0 -- wget -qO- http://localhost:8080/healthz

{{- if .Values.ingress.enabled }}

The app should be reachable at:
  http{{ if .Values.ingress.tls.enabled }}s{{ end }}://{{ .Values.ingress.host }}/
{{- else }}

No Ingress is enabled (ingress.enabled=false). Port-forward to reach it locally:
  kubectl port-forward -n {{ .Release.Namespace }} svc/{{ include "nirdosha.fullname" . }} 8080:{{ .Values.service.port }}
{{- end }}

{{- if not .Values.auth.enabled }}

NOTE: auth.enabled=false — every request is unauthenticated and every
`requires(...)`-gated fn is unreachable (401 for everyone). Set
auth.enabled=true with a real jwksSecretName/issuer/audience before
exposing this outside a trusted network.
{{- end }}

{{- if .Values.presence.enabled }}

`workflow`'s notify() live-push path is enabled: the presence-gateway
sidecar is deployed alongside nirdosha, reachable at
  ws://{{ include "nirdosha.fullname" . }}:{{ .Values.presence.gateway.port }}/ws
from inside the cluster (port-forward or Ingress it the same way as the
main http port if browsers need to reach it directly). See
crates/presence-gateway/README.md for the client protocol.
{{- else }}

NOTE: presence.enabled=false — notify() will always silently take the
offline (send_email) path; nothing terminates a live browser WebSocket
connection. Set presence.enabled=true (with auth.enabled=true and
presence.redis.host set) to enable real-time push. See docs/ROADMAP.md Track
A5 / docs/WORKFLOW.md's presence-bridge section.
{{- end }}
